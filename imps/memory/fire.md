Compare the raw buffers with a length check first: `const a = Buffer.from(token), b = Buffer.from(key); if (a.length !== b.length || !crypto.timingSafeEqual(a, b)) → 401` (the pattern in `app/routes/sync.js`). Hashing a supplied token to check it against a stored hash verifier is a different design and is fine.
